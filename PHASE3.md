# Phase 3 — Policy validation

From the project root, with `.venv` active, run:

```powershell
python evaluate_policies.py
```

It creates `artifacts/policy_comparison.json`.

## Verify the API model is active
1. Keep/start the API with `python -m uvicorn app.main:app --reload`.
2. Open `http://127.0.0.1:8000/docs`.
3. Submit a workload to `POST /orchestrate`.
4. Confirm the response includes `"policy": "random_forest_synthetic_proxy"` and a `model_confidence` value.
5. If it reports `rule_based_baseline`, check that `artifacts/runtime_policy.joblib` exists under the project root and restart Uvicorn from that root.

## Research caveat
The synthetic dataset labels were generated by proxy assumptions. This comparison measures how well the policies match those assumptions; it does not establish that either policy lowers real cloud cost or latency. For research claims, collect repeatable measurements from actual serverless and container deployments, including latency, throughput, cold starts, resource use and provider-calculated cost.
